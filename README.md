# Coding Platform 🚀

## 📖 About the Project
**Coding Platform** is a modern, interactive web application designed to facilitate the learning process for programming students. The platform provides a structured curriculum divided into modules and components, offering integrated video lectures, interactive presentations, reading materials, and a seamless task submission system. It is built with a focus on user experience, security, and accessibility.

## ✨ Key Features
* **Modular Learning:** Content is organized into distinct modules and lessons for easy and intuitive navigation.
* **LLM-Generated Video Content:** Features innovative video materials and lecture recordings generated by Large Language Models (LLMs) to provide unique and enhanced learning perspectives.
* **Supplementary Resources:** A rich library of additional learning materials, including recommended programming books, external educational videos, and direct links to essential coding platforms.
* **Seamless YouTube Integration:** Native embedding of curated YouTube tutorials with real-time search and filtering, allowing students to explore a wide range of video content without leaving the app.
* **Multimedia Integration:** Embedded Google Drive videos and interactive Google Slides presentations directly within the platform.
* **Bilingual Support (i18n):** The platform seamlessly supports multiple languages (English and Georgian) using custom `react-i18next` configurations.
* **Task Submission:** Direct assignment submission via the platform using `EmailJS`, allowing students to send their work directly to instructors without a complex backend database.
* **Responsive Design:** Fully responsive and modern UI built with `Tailwind CSS`, ensuring a great experience across all devices (desktop, tablet, and mobile).
* **Secure Viewing:** Embedded materials (iframes) are sandboxed and restricted to prevent unauthorized downloading, external sharing, or opening in new tabs.

## 🛠️ Technologies & Tools Used
The platform leverages a modern and robust tech stack to ensure high performance, maintainability and a seamless user experience:

* **Core Framework:** * **React.js (v18+):** Used as the primary JavaScript library for building the dynamic, component-based user interface.
* **Build Tool & Environment:** * **Vite:** Utilized for blazing-fast Hot Module Replacement (HMR) during development and highly optimized static asset bundling for production.
* **Routing & Navigation:** * **React Router DOM (v6+):** Handles client-side routing, enabling a smooth Single Page Application (SPA) experience with dynamic URL parameters (e.g., for individual lesson views).
* **Styling & UI:** * **Tailwind CSS (v3+):** A utility-first CSS framework used for rapid, responsive, and highly customizable UI design.
  * **PostCSS:** Employed alongside Tailwind for parsing and transforming CSS safely and efficiently.
  * **Lucide React:** Provides a clean, consistent, and highly customizable set of vector SVG icons across the platform.
* **Internationalization (i18n):** * **react-i18next:** Powers the dynamic, bilingual (English and Georgian) translation system, allowing instant language switching without page reloads.
* **Backend-as-a-Service / APIs:** * **@emailjs/browser (EmailJS):** Enables secure, serverless form submissions, allowing students to submit task links and details directly to instructors' inboxes.
* **Content Integration & Media:**
  * **Google Workspace Embeds:** Securely sandboxed iframes for displaying Google Docs (reading materials) and Google Slides (presentations).
  * **Google Drive Video API:** Integrated for streaming custom lecture recordings directly on the platform.
  * **YouTube Iframe API:** Used to embed supplementary educational videos with custom UI wrappers.
* **Data Management:**
  * **Local JSON Database (`db.json`):** Acts as a lightweight local data store to manage and organize course modules, lesson links, and video metadata structurally.
* **Package Management:**
  * **npm:** Node Package Manager used for tracking and installing all project dependencies (`package.json`, `package-lock.json`).
